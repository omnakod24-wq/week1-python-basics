# Week 4: Data Visualization and Complete Data Analysis

## Project overview
This project analyzes the supplied e-commerce sales CSV with pandas and creates bar, line, and pie charts with Matplotlib. It demonstrates the complete workflow: load, validate, clean, analyze, visualize, and report.

## Folder structure
- main.py: analysis pipeline and chart generation
- data/sales_data.csv: practice dataset (100 records)
- visualizations/: generated PNG charts
- report/analysis_report.md: written findings and chart links
- requirements.txt: Python dependencies
- test_cases.txt: validation checklist
- screenshots/README.md: instructions for capturing real terminal evidence

## Setup
1. Install Python 3.
2. Open a terminal in this folder.
3. Install dependencies: py -m pip install -r requirements.txt on Windows, or python3 -m pip install -r requirements.txt on macOS/Linux.
4. Run: py main.py on Windows, or python3 main.py on macOS/Linux.

## Charts
The script creates sales_by_product.png (bar chart), monthly_sales_trend.png (line chart), and sales_by_region.png (pie chart) in visualizations/.

## Technical details
- pandas loads and summarizes the CSV.
- Dates and numeric values are converted to appropriate types.
- Exact duplicate records and rows missing essential fields are removed.
- Revenue is recalculated as Quantity multiplied by Price.
- Matplotlib generates labeled charts and saves PNG images.
- Missing files and invalid data are handled with clear error messages.

## Report
Run the program to generate or update report/analysis_report.md with metrics and data-based insights.

## Testing
See test_cases.txt for checks covering row count, columns, revenue calculation, cleaning, report generation, and chart outputs.

## Visual evidence
Charts are generated by the program. The screenshots folder explains how to capture an actual terminal screenshot on your computer.
