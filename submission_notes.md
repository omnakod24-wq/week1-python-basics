# Week 1 Submission Notes

## Project overview
The Personal Introduction Program asks the user for their name, age, city, course, and hobby, then displays the information in a readable format.

## What I learned
- Programming means writing instructions for a computer to perform a task.
- Variables store values for later use.
- `input()` accepts information from the user.
- `print()` displays information on the screen.
- f-strings insert variable values into text.
- `.strip()` removes extra spaces from the beginning and end of input.

## Code structure
- `personal_intro.py` — the Python program.
- `README.md` — project overview and setup instructions.
- `requirements.txt` — package requirements (none are needed beyond Python itself).
- `sample_output.txt` — an example of program output.
- `test_cases.txt` — manual testing examples.
- `screenshot.png` — add your own real screenshot of the program running in a terminal before final submission.

## How to create the required screenshot
1. Open the project folder in VS Code.
2. Open the terminal and run `py personal_intro.py`.
3. Enter example details when prompted.
4. Make sure the output is visible in the terminal.
5. Take a screenshot using `Win + Shift + S` on Windows.
6. Save the image as `screenshot.png` in the project root and upload it to GitHub.

A genuine screenshot should be captured from your own running program; this repository does not include a fabricated screenshot.
