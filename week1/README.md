# Week 1 — Python Basics: Personal Introduction

## Project overview
This beginner Python project asks for five details and prints a short introduction:
- Name
- Age
- City
- Course
- Hobby

## Files
- `personal_intro.py` — program source code
- `requirements.txt` — notes about dependencies
- `test_cases.txt` — manual test cases

## Requirements
- Python 3.10 or newer
- No third-party packages required

## Run the program on Windows
1. Open this `week1` folder in VS Code.
2. Choose **Terminal → New Terminal**.
3. Run:

   ```powershell
   py personal_intro.py
   ```

   If that command does not work, try `python personal_intro.py`.

## Example
Use these sample answers when prompted:

```text
Enter your name: OMPRAKASH NARAYAN NAKOD
Enter your age: 21
Enter your city: Pune
Enter your course: B.Sc (Computer Science)
Enter your hobby: Coding

--- My Introduction ---
My name is OMPRAKASH NARAYAN NAKOD.
I am 21 years old.
I live in Pune.
I am studying B.Sc (Computer Science).
My hobby is Coding.
```

## What I learned
- Variables store information.
- `input()` accepts information from the user.
- `print()` displays information.
- `.strip()` removes extra spaces at the beginning and end.
- f-strings insert variable values into sentences.

Follow the manual cases in `test_cases.txt`.
