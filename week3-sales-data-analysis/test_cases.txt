WEEK 3 SALES DATA ANALYSIS - TEST CASES
========================================
1. CSV row count: expect 100 data rows.
2. Required columns: Product, Quantity, Unit_Price, Total_Sales, Region must exist.
3. Revenue calculation: Total_Sales is recalculated as Quantity * Unit_Price.
4. Summary metrics: script prints total revenue, average sale, and top product by revenue.
5. Missing essential values: records missing Product, Quantity, or Unit_Price are removed.
6. Missing optional region: a missing Region is filled with Unknown.
7. Duplicate rows: exact duplicate rows are removed before analysis.
8. Invalid numeric values: invalid numeric text is converted to missing and excluded if essential.
9. Report generation: running sales_analysis.py creates or updates analysis_report.md.
10. Empty cleaned dataset: script reports that no valid records are available rather than crashing.
