# Week 1: Python Basics

## Project
A simple Python program that asks the user for personal details and prints a short introduction.

## Concepts used
- Variables
- `input()` to receive user input
- `print()` to display output
- `.strip()` to remove extra spaces
- f-strings to format text

## Requirements
- Python 3.10 or newer (Python 3.13 is fine)
- No external libraries are required

## How to run

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open the terminal in that folder.
4. Run:

```bash
py personal_intro.py
```

If `py` does not work, try:

```bash
python personal_intro.py
```

## Example

```text
Enter your name: OMPRAKASH NARAYAN NAKOD
Enter your age: 21
Enter your city: pune
Enter your course: B.Sc(cs)
Enter your hobby: coding

--- My Introduction ---
My name is OMPRAKASH NARAYAN NAKOD.
I am 21 years old.
I live in pune.
I am studying B.Sc(cs).
My hobby is coding.
```

These are the details used for the example. When you run the program, enter these values at the prompts.

## Common error: file not found

If Python says it cannot open `personal_intro.py`, make sure:
- The file is saved with the exact name `personal_intro.py`.
- The terminal is open in the `week1-python-basics` folder.
- You can see the file in the VS Code Explorer.

You can check the current folder with:

```powershell
dir
```
