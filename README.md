# Week 1 — Python Basics

This repository contains the Week 1 beginner Python assignment in the `week1/` folder.

## Open the project
Go to the [Week 1 project folder](week1/).

## Project files
- [README.md](week1/README.md) — instructions and example output
- [personal_intro.py](week1/personal_intro.py) — Python program
- [requirements.txt](week1/requirements.txt) — dependencies
- [test_cases.txt](week1/test_cases.txt) — manual test cases

## Run on Windows
Open a terminal inside the `week1` folder and run:

```powershell
py personal_intro.py
```

No third-party packages are required. If your assignment requires a screenshot, capture the real program output on your computer and upload it as `week1/screenshot.png`.
